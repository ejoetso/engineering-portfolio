I’m a software engineer and higher-education lecturer. I build applications for people running classes, managing assessments, or coordinating student projects. Teaching gives me a close view of where those workflows break down, from getting a room of students into a live session to giving educators access to the right course records.

My approach to forward-deployed engineering starts with the people who will use and operate the system. I map the workflow, build a version they can try, and document the setup and deployment so someone else can run it. My recent work includes browser-based collaboration, self-hosted education software, and AI features embedded in tools educators already use.

## Where I can help

- **Workflow discovery and prototyping.** Map the user roles and the steps they need to complete. Build a prototype that educators, administrators, and technical teams can evaluate together.
- **Full-stack application delivery.** Build TypeScript and React applications with Node.js APIs, role-scoped access, reporting, and durable data storage.
- **Real-time collaboration.** Build browser-based tools that combine WebRTC media, WebSocket synchronisation, QR joining, and participant controls.
- **Applied AI integration.** Add model-assisted features such as classroom summaries and quizzes, with clear configuration and a workflow that still works when AI features are disabled.
- **Self-hosted deployment and handoff.** Package services with Docker Compose and document environment configuration, persistent data, and the steps operators need to run an evaluation.
